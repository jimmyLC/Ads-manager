# 廣告素材規格（合作方版）

> 適用系統：Ads-manager　服務站點：`javis.fyi`、`javid.fyi`
> 版位：`javis:watch-below`（影片頁播放器下方）、`javid:result-foot`（辨識結果下方）

---

## 1. 一句話規格

**圖片寬高比固定 16/5（3.2:1）**；桌機 **1280×400**、手機 **640×200**（各另提供 @2x 雙倍尺寸）。
同一份素材可同時投放 javis 與 javid。

---

## 2. 尺寸表

| 版位 | 裝置 | 尺寸 | @2x 尺寸 | 比例 |
|---|---|---|---|---|
| `javis:watch-below` | 桌機 | 1280×400 | 2560×800 | 16/5 |
| `javis:watch-below` | 手機 | 640×200 | 1280×400 | 16/5 |
| `javid:result-foot` | 桌機 | 1280×400 | 2560×800 | 16/5 |
| `javid:result-foot` | 手機 | 640×200 | 1280×400 | 16/5 |

- 桌機實際渲染寬度：javis 970px、javid 920px（等比縮放至 970×303 / 920×287.5）。
- 手機實際渲染寬度：視窗寬度（375px → 375×117）。
- **系統會拒收尺寸或比例不符的素材**（同一則廣告的所有變體必須同為 16/5）。

---

## 3. 檔案要求

| 項目 | 要求 |
|---|---|
| 格式 | JPG / PNG / WebP（GIF 不接受） |
| 大小 | 桌機 ≤512KB、手機 ≤256KB |
| 色彩 | sRGB |
| 命名 | 由後台上傳時指定，不需要自行命名（系統以 SHA-256 儲存） |

## 4. 內容要求

- **留白**：四周至少 40px 安全邊距，避免裁切時切到文字。
- **對比**：javis 為淺色 UI → 建議深色文字／淺底；javid 為深色 UI → 建議亮色文字／深底。
- **可讀性**：主要文案在 1280×400 之下仍應清晰；避免 10px 以下字級。
- **禁止**：
  - 彈跳視窗、自動播放、蓋住頁面內容
  - 誤導性文案（如假裝是系統訊息）
  - 違反 SFW 內容政策
  - 未經許可的第三方商標使用

## 5. 連結

- 目標網址必須是 **https**。
- 系統使用同源 302 轉跳（點擊先經本站 `/api/promo/out/...` 再轉出），無第三方網域。
- 站上會自動加上 `rel="sponsored nofollow noopener"`、`target="_blank"`。
- 桌機與手機可給**不同**連結（各 1 個），也可只給 1 個（兩種裝置共用）。

## 6. 排期與成效

- 可設定上架日、下架日、權重（輪替機率）、每日曝光上限、曝光/點擊目標值（達標自動下架）。
- 成效數據：曝光、點擊、點擊率（CTR）、可選的轉換追蹤（pixel 或回呼 URL）。
- 報表維度：日期 × 廣告 × 版位 × 國別 × 裝置，可匯出 CSV。

## 7. 原生卡（Native）

不想用圖片，也可以用原生卡——由網站前端元件渲染成融入版面的卡片，視覺更一致：

| 欄位 | 必填 | 長度 | 說明 |
|---|---|---|---|
| 標題 | ✅ | ≤60 字 | 主標題 |
| 描述 | ✅ | ≤140 字 | 一到兩句 |
| 按鈕文字 | ✅ | ≤20 字 | 例如「立即下載」 |
| 按鈕連結 | ✅ | https | 目標網址 |
| 品牌 logo | ⭕ | 1:1 或 4:3 | 建議 128×128 以上 |
| 縮圖 | ⭕ | 16:9 | 建議 640×360 以上 |
| 替代文字 | ✅ | — | 無圖時顯示 |

## 8. 素材審核

- 建立後為**草稿**狀態，管理員確認後才上線。
- 上線前請自我檢查：尺寸比例、檔案大小、留白、連結可達、文案無誤導。
- 到期後廣告自動下架，不會殘留。
